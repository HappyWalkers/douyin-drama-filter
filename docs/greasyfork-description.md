# 抖音剧情过滤：精选首屏补漏

在抖音网页版精选页隐藏短剧、剧情演绎、情景搞笑和 AI 漫剧卡片，补充初始卡片的过滤。范围是 `https://www.douyin.com/jingxuan` 及其子路径。

脚本可独立在精选页使用，**不处理首页推荐播放器或搜索结果**。若需要推荐流过滤，可另装 [WhiteSevs 的「抖音优化」](https://greasyfork.org/zh-CN/scripts/494643-抖音优化)，配合剧情过滤规则。这个补漏脚本不包含原作者的代码，也不会自动修改其设置。

## 如何识别

读取当前卡片已有的视频元数据，依据短剧文案、话题、合集、平台剧情分类、作者虚构声明，以及漫剧和情景剧线索隐藏卡片。带 AI 生成声明且被平台归为动漫或影视剪辑的内容也可能被屏蔽。

默认启用强力范围，可能误伤部分动画、影视相关内容或 AI 文化展示。将源码中的 `const STRONG = true` 改为 `false` 可仅保留明确的短剧标记和短剧关键词过滤。

## 权限与限制

- `@grant none`，无第三方依赖，无网络请求。
- 不读取 Cookie、登录凭据，不发送「不感兴趣」。
- 只在本地隐藏匹配卡片，并暂停隐藏卡片内的视频。
- 不识别画面或语音，缺乏标签和文案的剧情仍可能漏过。
- 依赖当前页面结构，抖音更新后可能失效。
- 测试样本的屏蔽比例不能代表全站识别准确率。
